# Video Processing for Strike Map

Когда пользователь просит добавить видео к событию на карте, всегда следуй этому алгоритму:

1. **Скачивание:** Используй локальную утилиту `yt-dlp.exe` (находится в корне проекта) для скачивания оригинального видео по ссылке.
2. **Сжатие:** Используй локальную утилиту `ffmpeg.exe` (также в корне проекта) для сжатия скачанного видео.
3. **Параметры сжатия:** Итоговый файл должен весить **строго меньше 2 МБ**. Для этого используй команду с битрейтом видео 200k и аудио 48k. Пример:
   ```powershell
   .\ffmpeg.exe -i "input.mp4" -b:v 200k -b:a 48k -vcodec libx264 -acodec aac "output.mp4" -y
   ```
4. **Сохранение:** Готовое сжатое видео сохрани в папку `video/` внутри проекта.
5. **Обновление данных:** Добавь относительный путь к видео (например, `"video/kstovo.mp4"`) в массив `"images"` нужного события в файле `data.js`.
